📋 What makes this a Block Theme?

🎨 Block Theme Features:

  • theme.json — defines colors, typography, spacing, and block settings
  • /templates/ — HTML templates for index, single, page, archive, search, 404
  • /templates/woocommerce/ — WooCommerce templates (archive-product, single-product, cart, checkout)
  • /parts/ — Reusable template parts (header, footer)
  • Full Site Editor — edit everything visually in Appearance → Editor
  • Block-based header and footer — drag-and-drop customizable

Same UI features as before: loading screen, modals, slide panel, sticky footer, custom add-to-cart.

⚡ After installing, go to Appearance → Editor to customize headers, footers, and templates with blocks.
All minimalist styling is preserved and editable.
